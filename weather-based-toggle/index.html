Privacy & Data

  • Location data is stored only in your browser's local storage and is never sent to our servers.
  • Weather data is fetched from Open-Meteo (free, no API key required, privacy-friendly).
  • Only city-level coordinates are used — precise GPS data is rounded before any API call.
  • Cached weather data is retained for up to 30 minutes and then automatically refreshed.
  • You can clear all stored data at any time using the button below.
