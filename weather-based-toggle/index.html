⚙️ Override Settings

Override the weather theme for specific projects or boards. When disabled for a project, that project will use the standard theme regardless of the global toggle.

Per-project and per-board overrides are available when this feature is integrated with your project management tool.

🎨 Available Themes

Each weather condition maps to a unique theme identified by both color and icon + text label — ensuring accessibility for all users, including those with color vision deficiencies.

🔒 Privacy & Data Handling

We take your privacy seriously. Here's how we handle your data:

  • Location data is coarsened to ~11 km precision before use.
  • No server storage — all preferences are saved in your browser's local storage only.
  • Weather data is fetched from Open-Meteo (free, open-source, no API key required, no tracking).
  • All data is cleared when you disable the weather theme.
  • No data is shared with third parties beyond the weather API request.
  • Cached data expires after 30 minutes and is stored locally only.
♿ Accessibility Statement

This feature is designed with accessibility as a core requirement:

  • Non-color cues: Weather state is communicated via icons and text labels, never by color alone (WCAG 1.4.1).
  • High contrast: All text meets WCAG AA contrast requirements (minimum 4.5:1 ratio).
  • Color-blind safe: Themes are distinguishable under protanopia, deuteranopia, and tritanopia.
  • Keyboard accessible: All controls are fully operable via keyboard (WCAG 2.1.1).
  • Screen reader support: ARIA roles, labels, and live regions provide full screen reader compatibility.
  • Reduced motion: Animations are disabled when prefers-reduced-motion is set.
  • High contrast mode: Full support for Windows High Contrast and forced-colors mode.
  • Touch targets: All interactive elements meet the 44×44px minimum target size (WCAG 2.5.8).
